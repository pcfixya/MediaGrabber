## About this project

**MediaGrabber** is a personal, hobby-scale Android fork of [Seal Plus](https://github.com/MaheshTechnicals/Sealplus) by [Mahesh Technicals](https://github.com/MaheshTechnicals), which itself builds on the original [Seal](https://github.com/JunkFood02/Seal) by [JunkFood02](https://github.com/JunkFood02). It's a rebrand + light customization (own name/icon, app-lock naming, Polish localization) maintained by [pcfixya](https://github.com/pcfixya) for personal and friends' use — it is **not** affiliated with, endorsed by, or maintained by JunkFood02 or Mahesh Technicals.

For now it's distributed as APKs from [GitHub Releases](https://github.com/pcfixya/MediaGrabber/releases) — not published on Google Play or F-Droid.

### What's different from Seal Plus

- New name, icon, splash screen and in-app branding (this repo, not `com.maheshtechnicals.sealplus`)
- Full Polish translation (`values-pl`) in addition to English, with an in-app language switcher
- Auto-update checks this repo's own [Releases](https://github.com/pcfixya/MediaGrabber/releases) instead of Seal Plus's
- The old "Support Developer" donation flow (UPI/PayPal/GitHub Sponsors/crypto wallet tied to Mahesh Technicals) was removed; if you'd like to support **this fork** specifically, see [Buy Me a Coffee](https://buymeacoffee.com/neuralpulse)
- Everything else — the download engine, UI, and feature set — comes from Seal Plus v3.0.0. See [CHANGELOG.md](CHANGELOG.md) for the full upstream history this fork was built on.

## ✨ Key Features

Inherited from Seal Plus / Seal:

- **Universal downloader** for 1000+ sites via [yt-dlp](https://github.com/yt-dlp/yt-dlp) (YouTube, Instagram, TikTok, Twitter/X, Facebook, Reddit, Twitch, SoundCloud, and more)
- **Audio extraction** with metadata/thumbnail embedding via [mutagen](https://github.com/quodlibet/mutagen) (MP3, M4A, OPUS, FLAC, WAV)
- **Playlist & batch downloads**, with progress tracking and resume support
- **High-speed downloads** via an embedded [aria2c](https://github.com/aria2/aria2) engine
- **Subtitle support** — embed or download separately, auto-generated or manual
- **Custom yt-dlp commands** with saved templates for power users
- **Download manager** with history, search, and batch operations
- **Gradient Dark theme** with glassmorphism UI (Settings → Look & Feel)
- **App Lock** with PIN/biometric authentication
- **More Tools hub** — batch URL import, thumbnail download, video info export, comment download
- **Material Design 3** with dynamic color (Android 12+)

## ⬇️ Installation

1. Download the APK matching your device's architecture from [Releases](https://github.com/pcfixya/MediaGrabber/releases/latest) — if unsure, get **universal**
2. Enable "Install from unknown sources" in Settings → Security
3. Open the downloaded APK and follow the prompts
4. Grant the permissions the app asks for when needed

> [!WARNING]
> Only download MediaGrabber from this repo's [Releases page](https://github.com/pcfixya/MediaGrabber/releases). Never from third-party sources.

### Device compatibility

| Requirement | Specification |
|---|---|
| **Minimum Android** | 7.0 (API 24) |
| **Target Android** | 17 (API 37) |

### Architecture support

- **arm64-v8a** — recommended for most modern devices (2017+)
- **armeabi-v7a** — older 32-bit ARM devices
- **x86_64 / x86** — Intel/AMD devices, emulators
- **universal** — works everywhere, larger file size

## ❓ FAQ

<details>
<summary><b>Is MediaGrabber safe? Does it collect my data?</b></summary>

- 100% open source — read the code yourself
- No analytics, no ads, no trackers
- No network access beyond what's needed to fetch/download media
- Licensed under GPL-3.0

</details>

<details>
<summary><b>How does auto-update work?</b></summary>

The app checks this repo's GitHub Releases for newer versions and offers a one-click APK update. Can be turned off in Settings → About.

</details>

<details>
<summary><b>What's the relationship between MediaGrabber, Seal Plus and Seal?</b></summary>

MediaGrabber is a fork of Seal Plus, which is itself a fork of Seal. All the download/UI functionality comes from that lineage — this fork's own changes are limited to branding, Polish localization, and removing the previous donation integration. See Acknowledgments below for full credit.

</details>

<details>
<summary><b>I'm getting download errors — what do I try?</b></summary>

1. Update yt-dlp: Settings → About → Update yt-dlp
2. Check your internet connection
3. Some sites need a custom command — see [supported sites](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md)
4. [Open an issue](https://github.com/pcfixya/MediaGrabber/issues) with details if it persists

</details>

### Building from source

```bash
# Requirements
- Android Studio (recent)
- JDK 21
- Android SDK (compileSdk/targetSdk 37, minSdk 24)

git clone https://github.com/pcfixya/MediaGrabber.git
cd MediaGrabber
./gradlew assembleDebug     # debug build
./gradlew assembleRelease   # release build (needs your own keystore.properties)
```
